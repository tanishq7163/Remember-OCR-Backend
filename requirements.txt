# ── SYSTEM REQUIREMENTS (install manually) ──────────────────

Node.js >= 20.0.0
  Download : https://nodejs.org/en/download
  Check    : node -v

npm >= 10.0.0
  Included with Node.js
  Check    : npm -v

Ghostscript >= 10.0.0   [OPTIONAL — only needed for scanned PDFs]
  Download : https://www.ghostscript.com/releases/gsdnld.html
  Windows  : run the 64-bit installer (gs1000w64.exe or similar)
  Check    : gswin64c --version


# ── INSTALL ALL NPM PACKAGES ────────────────────────────────
#
#   npm install
#
# That single command installs every package listed below.
# ────────────────────────────────────────────────────────────
